# PORTING_DECISIONS — журнал решений

## D0. Путь переноса: E (полный порт невозможен в текущих условиях) + D частично
Варианты из Promt: A (исходники игры) — нет; B (исходники движка) — нет + нужна Xbox360-сборка Torque с xenon-ветвью + лицензия; C (совместимый runtime) — нет (TGEA runtime под 360 отсутствует); D (частичная реконструкция) — выполняется для BMP/TGA+HLSL+ввода; E — итог для играбельного порта. Причина: `plan verdict BLOCKED 8x UNSUPPORTED`, CPU x86, закрытый EXE. Решение зафиксировано, не пересматривать без новых материалов (исходники/лицензия движка).

## D1. Не декомпилировать EXE в «исходники»
Причина: x86→PPC рекомпиляция с восстановлением Torque-логики, D3D-устройств, скриптовых связей невозможна легальными средствами в этом проекте; `SECURITY.md` запрещает исполнение/загрузку чужого EXE. Вместо этого — статический PE-парсинг + инвентаризация + честный plan. Статус: принято, PASSED (анализ воспроизводим).

## D2. Найден ложноположительный учёт в `assets convert` — зафиксировать, не скрывать
Факт (`Converter.cpp:105-108`): цикл считает `total` только для `.bmp/.tga`, остальные 1601 файл молча `continue` без статуса. Итог `total=6 converted=6` при 1607 файлах в каталоге выглядит как «всё сконвертировано», хотя PNG/JPEG пропущены. Это нарушает Promt §5 (стадия должна иметь явный статус). Решение: в отчётах писать `total_bmp_tga=6 + ignored_non_bmp_tga=1601 (734 PNG/JPEG unsupported)`, verdict конвертера считать PARTIAL для игры. Код не менялся в этой итерации (требует ревью + тест); отчётность исправлена здесь.

## D3. Профили ужатия: не единый 480p
Promt запрещает единый 480p для всего. Факт: применён `xbox360-480p` только к 6 BMP (другого конвертер не умеет). Для PNG/JPEG после появления декодеров — выбирать по назначению (UI 1:1, террейн/скайбокс downscale + mips, normal/mask линейный путь). Пока: PARTIAL.

## D4. Шейдеры: настоящий XDK fxc, падение не скрывать
`ShaderConvert.cpp:55-97 runFxc` выполняет реальный `C:\Program Files (x86)\Microsoft Xbox 360 SDK\bin\win32\fxc.exe`, стадия из имени (`stageOf`), unknown пробует оба профиля (оракул — сам fxc). `convertDir:246-248` возвращает `Fail` при `failed>0` — правильно. Итог `170/176` с `X4509` — PARTIAL, требуется правка `refractPixBumpV.hlsl` + ревью SM1-фолбэков. `canada_shaders_xbox/*.vso/.pso + pc2c-shader-report.json` — артефакты.

## D5. Ввод: драфты, не код
`TorqueGen` сохраняет функции дословно, key→axis — в комментарий, устройства `UNVERIFIED`, вердикт `UNPROVEN`. `canada_gamepad.cs (binds=14 active=3 drafts=0 warnings=11)` и `profiles/canada_hunt_gamepad.json (14 действий, 0 конфликтов)` — REVIEW DRAFT. Без подтверждения движкового joystick-пути и `JoystickEnabled=1` не интегрировать. Статус: PARTIAL.

## D6. Сборка: только новые XEX, не «порт игры»
`Xbox360Backend planBuild + buildXboxSample` выполняет реальный `MSBuild Release|Xbox 360 (cl 16.00.11886/link 10.00.11886/imagexex)` — RUNTIME_VERIFIED для `minplay`/`canadaview` (XEX2 magic, Xenia boot 2026-10-13). `canadaview.xex 2891776B + hunt0..5.bmp` пересобран 2026-10-13 `ok:true`. Это вьювер BMP, не игра — не называть портом (Promt §8, §10).

## D7. Работать с копией — соблюдено частично
Оригинал `C:\Realistic Hunting Games\...` только читался (scan/parse/convert читают, пишут в `%TEMP%\opencode\canada_*`). Копия игры не создавалась (нет нужды дублировать 207МБ ради чтения). Запись в оригинал: не выполнялась. `prefs.cs/console.log` изменены самой игрой при её запуске пользователем, не нами.

## D8. Xenia как проверка, не доказательство консоли
Xenia master D3D12 — легитимная тест-среда из `release-builds-windows`, вне репозитория. Результат эмулятора ≠ devkit. Devkit-прогон — открытый блокер. Xenia на этой машине не найдена (`where xenia.exe` — нет), повторный запуск не выполнялся — статус предыдущего прогона сохранён из `XBOX360_BACKEND.md`, новый — NOT_RUN.
