# Поддерживаемые форматы (MVP 0.1.0)

Легенда: ✅ полная поддержка · ⚠️ детект без конвертации · ❌ неизвестно/не трогаем.

## Изображения (Asset Pipeline)

| Формат | Детект | Конвертация | Примечания |
|---|---|---|---|
| BMP 24-bit BI_RGB | ✅ magic `BM` + заголовок | ✅ | Непрозрачный, выход 24-bit |
| BMP 32-bit BI_RGB / BI_BITFIELDS | ✅ | ✅ | Alpha сохраняется; полностью непрозрачный → выход 24-bit |
| BMP paletted (≤8bpp), 16bpp, RLE | ✅ | ❌ честная ошибка | Не угадываем палитру |
| TGA type 2 (truecolor 24/32) | ✅ заголовок | ✅ | Учитывается origin-бит |
| TGA type 10 (RLE 24/32) | ✅ | ✅ | С защитой от переполнения run |
| TGA colormapped/grayscale-16/16bpp | ✅ | ❌ честная ошибка | — |
| PNG, JPEG, GIF, TIFF, WEBP | ⚠️ magic | ❌ | Декодеры — backlog Phase 3 (нужна зависимость или свой код) |
| DDS (`DDS `) | ⚠️ magic | ❌ | Полезная нагрузка требует исследования GPU-форматов/tiling (см. XBOX360_BACKEND.md); файл сохраняется как есть |

Семантика по имени: `*normal*/*nrm*/*nmap*` → normal (box-average +
ренормализация, обычный цветовой фильтр запрещён); `*mask*/*rough*/*metal*/`
`*ao*/*spec*/*gloss*/*height*/*bump*` → mask (линейное box, без смены
цветового пространства); остальное — color (bilinear, апскейл запрещён).

## Исполняемые

- PE32 / PE32+ (`MZ` → `PE\0\0`): arch x86/x86-64/arm/arm64/ppc, импорты
  (cap 20000, ordinal-метки), экспорты (cap 500), linker-версия → hint
  компилятора, Rich-маркер (эвристика), .NET COM-дескриптор, delay-imports
  (фиксируются, не перечисляются).
- XEX (`XEX2`): только сигнатура в скане; парсер XEX — вне MVP.
- ELF: только сигнатура.

## Контейнеры/аудио/модели/шейдеры/конфиги

Детект по magic+расширению (ZIP/RAR/7Z/CAB, WAV/OGG/FLAC/MP3, FBX/OBJ/X/…,
FX/HLSL/CSO/…, INI/XML/JSON/LUA/…), конвертации в MVP нет — записи
`REQUIRES_RESEARCH`/inventoried-only. Проприетарные контейнеры не
распаковываются без зарегистрированного декодера.
