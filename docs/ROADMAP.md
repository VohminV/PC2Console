## Phase 0 — аудит ✅ (2026-10-13)

Репозиторий пуст (только ТЗ); окружение проверено: XDK 21256 полный,
VS2010, MinGW 15.2, CMake 4.4.4. Документы созданы.

## Phase 1 — ядро и CLI ✅

Конфиг, CLI (все команды ТЗ), лог, безопасный обход, тесты. Нулевые внешние
зависимости.

## Phase 2 — анализ ✅

PE-анализатор, импорты/зависимости, инвентаризация, JSON-отчёты.

## Phase 3 — Asset Pipeline ✅ (частично)

BMP/TGA, mipmap, профили (480/360/240/120p, conservative, balanced), хеши,
манифест, verify, оценки памяти. Backlog: PNG/JPEG-декодеры, аудио, Xenos writer
(только после спеки + векторов).

## Phase 4 — переносимость ✅

ApiDb, модель ограничений, `pc2c plan`, проверка на синтетике.

## Phase 5 — Xbox 360 SDK и backend ⏳ СЛЕДУЮЩИЙ

1. Авторский минимальный сэмпл на XDK-заголовках (без копирования закрытого кода).
2. Реальный `cl` + `link` через `xdkvars.bat` окружение (легитимный установленный XDK).
3. `imagexex` упаковка → проверка формата.
4. Запуск в легитимной тест-среде; только после этого `ready=true`.
5. Зафиксировать точные команды сборки в XBOX360_SDK.md.

## Phase 6 — графическая адаптация ⏳

Промежуточный графический интерфейс, подтверждённые преобразования D3D9→Xbox,
сэмпл с выводом.

## Phase 7 — перенос конкретной игры ⏳

Игра с открытым кодом → карта зависимостей → минимальный сценарий →
замеры. Не раньше Phase 5.

## Phase 8 — PS3 ⏳

Отдельный backend + диагностика только после результата Xbox 360.
