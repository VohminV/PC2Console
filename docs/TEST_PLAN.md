# План тестирования

## Автоматические (реализовано, `pc2c test` / `ctest`)

Синтетические фикстуры генерируются в runtime во временной директории —
никаких бинарных блобов и чужих игр в репозитории.

| # | Проверка |
|---|---|
| 1 | SHA-256: векторы `abc`, пустой ввод |
| 2 | JSON dump/parse roundtrip; garbage отклоняется |
| 3 | PE32: arch x86, импорты DLL+символы, DX-hint d3d9, linker 10.0 → VS2010-hint |
| 4 | PE32+: arch x86-64 |
| 5 | Битые/урезанные/отсутствующие PE → честная ошибка, без падений |
| 6 | BMP24 roundtrip (порядок каналов, opaque), BMP32 alpha сохраняется |
| 7 | TGA raw + RLE-декод; урезанные отклоняются |
| 8 | Ресайз: точные размеры, long-side cap, запрет апскейла |
| 9 | Профили 480p…120p/conservative/balanced; неизвестный отклоняется |
| 10 | Normal-map: тег фильтра, ренормализация (~unit length); семантика по имени |
| 11 | Mipmaps 8×4 → 4 уровня до 1×1; оценка GPU 8×8×4 = 340 Б |
| 12 | Конвертер: convert → rerun skip (идемпотентность), вход не изменён (SHA), verify 2/2 |
| 13 | Пути Windows: `..\` и абсолютные блокируются, регистр расширения |
| 14 | Классификация API/CPU; неизвестная DLL → UNKNOWN |
| 15 | Probe SDK не падает; backend честно `ready=false`; planBuild — JSON |
| 16 | Plan без фейковых процентов, с caveat про импорты |
| 17 | E2E на синтетической игре (скан→PE→inventory→plan) |

Покрытие ТЗ: PE32/PE32+, импорты, форматы, масштаб, прозрачность, mipmap,
спецтекстуры, память, хеши, реран, сохранность входов, JSON, классификация API,
битые файлы, пути Windows, отсутствующий SDK, ошибки toolchain (честный
`ready=false` + блокеры).
