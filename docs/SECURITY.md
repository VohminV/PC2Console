# Безопасность

1. Игровые EXE/DLL **никогда не запускаются и не загружаются** (парсинг только
   чтением байтов с проверкой границ). Симлинки не проходятся.
2. Исходная игра не изменяется: все выводы — в `--output`, перезапись только
   с `--overwrite`, запись атомарная (tmp + rename).
3. Лимиты: файл 512 МБ, всего 32 ГБ, 500k файлов, PE 256 МБ, изображения
   256 МБ / 16384px / 256 Мпикс. Метаданным с безумными размерами — отказ,
   а не аллокация.
4. Распаковка: path traversal блокируется (`joinSafe`: запрет absolute и `..`
   с нормализацией); архивы без зарегистрированного декодера не трогаются.
5. DRM/лицензии/античит не обходятся; закрытые SDK не копируются в репозиторий
   и не распространяются; сомнительные установщики не запускаются.
6. Целостность: SHA-256 входов/выходов в манифесте, `verify` передекодированием,
   идемпотентный реран.
7. Диагностика SDK по умолчанию только читает ФС; выполнение известных бинарей
   SDK — только под явным `--probe-tools`. Удаление файлов пользователя —
   только явной командой пользователя (которой в MVP нет).
